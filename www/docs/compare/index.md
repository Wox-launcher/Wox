# Is Wox abandoned? Wox vs Flow Launcher, Raycast, and PowerToys (2026)

<ReleaseStamp />

## Is Wox abandoned?

Wox v1 development slowed for a long time. [Flow Launcher](https://github.com/Flow-Launcher/Flow.Launcher) grew out of that Windows v1 codebase and is the active Windows successor of that lineage.

This repository is **Wox v2**, a rewrite. It still ships stable releases in 2026 for Windows, macOS, and Linux. Check the [latest GitHub Release](https://github.com/Wox-launcher/Wox/releases) or the [changelog](/changelog/).

## Wox vs Flow Launcher

Flow Launcher is a Windows launcher in the Wox v1 family. It has a large Windows plugin scene and stays Windows-only.

Wox v2 is a native launcher for **Windows, macOS, and Linux**. If you need one launcher across those three desktops, Wox v2 is the project in this repo. If you only use Windows and already like Flow, Flow remains a solid choice.

## Wox vs Raycast

Raycast is more polished and is largely closed-source. It ships on macOS and Windows.

Wox is open source (GPL-3.0) and ships on Windows, macOS, and Linux. Use Raycast if you want that product's finish. Use Wox if you want an open-source launcher on all three platforms.

## Wox vs PowerToys Run

[PowerToys](https://learn.microsoft.com/windows/powertoys/) is Microsoft's Windows utility suite. PowerToys Run (and Command Palette) is one tool in that suite.

Wox is a dedicated launcher: plugins, clipboard history, file indexing, themes, and a store. PowerToys is the better pick when you already want the rest of the PowerToys collection. Wox is the better pick when you want a focused launcher, including on macOS and Linux.
