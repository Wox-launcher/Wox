# System Commands Plugin

System Commands runs power, volume, settings, and other system actions. It listens globally, so you can type `lock`, `sleep`, or `shutdown` without a keyword.

![The System Commands plugin](/images/plugin_sys.jpg)

## Quick Start

```text
lock
sleep
empty recycle
set volume 50
confetti
```

Available commands depend on the platform. Destructive actions such as shutdown ask for confirmation. `confetti` shows the fullscreen celebration overlay.
