# Selection Plugin

Selection acts on text or files you selected in another app. Use the selection hotkey, or query `selection` after Wox has captured the current selection.

## Quick Start

1. Select text or one file in another app.
2. Press the selection hotkey, or open Wox and type `selection`.
3. Copy the path, open the folder, preview the file, save to Notes, or run a Shell command.

`selection preview` returns only the file preview.

## Space Quick Look

On Windows, enable **Space Quick Look** in **Settings -> Plugins -> Selection**. Select one file in File Explorer or an open/save dialog and press `Space`. See [Preview](../../usage/preview.md).

macOS keeps this setting off because Finder already has Quick Look.
