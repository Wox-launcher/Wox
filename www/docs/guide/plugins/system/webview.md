# WebView Plugin

WebView previews a configured website inside Wox. It is available on Windows and macOS.

## Quick Start

```text
webview x
webview ig
```

Default keywords include `x` for X and `ig` for Instagram. Add your own keyword and URL in **Settings -> Plugins -> WebView**. You can set a user agent, inject CSS, or disable cache per site.

Bind a Query Hotkey with the **Preview Query** preset to open a site as a compact panel. See [Hotkeys](../../usage/hotkeys.md).

When you need the full browser, use the **Open in Browser** action.
