# Color Plugin

Color previews a color value and copies it in common formats. It recognizes six-digit hexadecimal colors globally, with or without `#`. The `color` keyword opens recent colors.

![The Color plugin](/images/guide/plugin_color.jpg)

## Quick Start

```text
#3B82F6
3B82F6
color
```

Actions copy HEX, RGB, or HSL. RGB/HSL text, three-digit HEX, and HEX values with alpha are not supported as input. Frequently used colors can be favorited and stay in history.
