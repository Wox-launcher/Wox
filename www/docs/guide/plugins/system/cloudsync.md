# Cloud Sync Plugin

Cloud Sync signs in and synchronizes settings across machines.

![The Cloud Sync plugin](/images/plugin_cloudsync.jpg)

## Quick Start

```text
sync
cloudsync
```

After sign-in, Wox shows per-item sync progress. Note text can sync; note images stay on the device. Some local-only settings are not uploaded.

Open **Settings -> Data** or run `sync` if you need to sign in again or check status.
