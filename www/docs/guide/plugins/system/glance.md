# System Glance Plugin

Glance shows live information beside the query box: time, date, battery, CPU, or memory.

## Quick Start

```text
glance
```

Enable Glance in **Settings -> Appearance**. Choose the primary glance shown in the query box. `glance` lists the available glances so you can switch or inspect them.

Glance is on by default. Hide the glance icon if you want a quieter query box.
