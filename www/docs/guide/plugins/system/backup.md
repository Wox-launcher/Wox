# Backup and Restore Plugin

Backup exports Wox settings and restores them later. Triggers are `backup` and `restore`.

![The Backup plugin](/images/plugin_backup.jpg)

## Quick Start

```text
backup
restore
```

Use this before resetting the data directory, or when moving settings to another machine. Cloud Sync can keep settings in sync without a manual export; see [Cloud Sync](./cloudsync.md).
