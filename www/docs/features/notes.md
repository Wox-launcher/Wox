# Floating notes in the launcher

<ReleaseStamp />

Wox includes floating Notes so you can capture something without switching to a separate notes app.

![A Wox Note with a checklist, table, and quote](/images/plugin_notes.png)

## What it is

Query `note` to search notes, or `note new` to create one. Each note opens in its own window. You can write rich text, checklists, tables, and attach images.

| Query | Result |
| --- | --- |
| `note` | Search and reopen notes |
| `note new` | Create a note |
| `note search invoice` | Filter by title or text |
| `note deleted` | Browse recently deleted notes |

Notes can be pinned, including across macOS Spaces. You can export Markdown, text, or HTML. Cloud Sync can sync note text; images stay on the device.

## Capture from other plugins

Clipboard, File Search, Screenshot, Selection, Quick Jump, and Shell can save the current item to Notes from the Action Panel. You do not have to copy it by hand first.

## How to use it

1. Open Wox and type `note new`.
2. Write in the note window. The launcher can hide; the note stays open.
3. Later, type `note` and pick the note to bring it back.

Deleted notes stay recoverable for 60 days, then they are purged.
