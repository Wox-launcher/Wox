# Clipboard history launcher with OCR search

<ReleaseStamp />

Wox includes a clipboard history launcher. Recent text and images stay searchable from the same window you use to open apps.

## What it is

Type `cb` to browse history. Filter by text, an alias, or **OCR text from copied images**. Favorites, copy, and paste back into the active app are built in — you do not need a separate clipboard manager for everyday reuse.

![Clipboard plugin history results](/images/system-plugin-clipboard.png)

## Why use it in a launcher

Clipboard history is a daily action. Keeping it next to app search, file search, and the action panel means you stay on the keyboard instead of switching tools.

Image OCR search shipped in Wox v2.4.2. Pasting clipboard images and emoji into the active window shipped in v2.4.3.

## How to use it

Setup, queries, actions, and retention settings are in the [Clipboard plugin guide](/guide/plugins/system/clipboard).
