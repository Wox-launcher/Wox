# 带 OCR 搜索的剪贴板历史启动器

<ReleaseStamp />

Wox 自带剪贴板历史。最近复制的文本和图片可以在同一个启动器窗口里搜索，不必再开一个剪贴板管理器。

## 是什么

输入 `cb` 查看历史。可以按文本、别名，或按**图片 OCR 文字**过滤。收藏、复制、粘贴到当前应用都在启动器里完成。

![剪贴板插件历史结果](/images/system-plugin-clipboard.png)

## 为什么放在启动器里

剪贴板是每天都在用的动作。把它和应用搜索、文件搜索、操作面板放在一起，可以一直留在键盘上。

图片 OCR 搜索出现在 Wox v2.4.2。把剪贴板图片和 emoji 粘贴到当前窗口出现在 v2.4.3。

## 怎么用

查询、动作和保留天数见[剪贴板插件指南](/zh/guide/plugins/system/clipboard)。
