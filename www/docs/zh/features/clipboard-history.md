# 带 OCR 搜索的剪贴板历史启动器

<ReleaseStamp />

Wox 内置剪贴板历史。最近的文本和图片都可以在打开应用的同一个窗口里搜索。

## 它是什么

输入 `cb` 浏览历史。可以按文本、标题，或 **复制图片中的 OCR 文本** 过滤。收藏、复制，以及粘贴回当前应用都是内置的，包括粘贴图片和 Emoji。

日常复用剪贴板，不需要再开一个独立的剪贴板管理器。

## 为什么放在启动器里

剪贴板历史是每天都会做的事。把它和应用搜索、文件搜索、操作面板放在一起，就可以一直留在键盘上，而不用切换工具。

图片 OCR 搜索在 Wox v2.4.2 加入。把剪贴板图片和 Emoji 粘贴到当前窗口在 v2.4.3 加入。

## 怎么用

设置、查询、动作和保留天数见 [剪贴板插件指南](/zh/guide/plugins/system/clipboard)。
