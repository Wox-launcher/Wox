# 启动器里的倒计时

<ReleaseStamp />

Wox 内置倒计时，可以在打开应用的同一个窗口里开始计时。

![从 Wox 开始一个 1 小时 5 分钟的计时器](/images/plugin_timer.png)

## 它是什么

```text
timer 5m
timer 1h meeting
timer 1h5m there is a meeting
```

`timer` 加上时长就会开始倒计时。时长后面的可选文字会变成计时器备注。正在运行的计时器会在 Wox 重启后保留。

| 动作 | 用途 |
| --- | --- |
| 开始并显示在桌面 | 开始计时并钉住浮层 |
| 在后台开始 | 开始计时但不显示浮层 |
| 暂停 / 继续 | 保留剩余时间 |
| 钉住 | 显示或隐藏桌面浮层 |

浮层本身不会持久化。重启后如果还需要浮层，重新打开 `timer` 再钉一次即可。

## 怎么用

1. 输入 `timer 25m focus`。
2. 按 `Enter` 开始并显示在桌面，或用操作面板在后台开始。
3. 之后输入 `timer` 即可暂停、继续或删除。
