# 在 Wox 里截图并搜索历史

<ReleaseStamp />

截图插件可以捕获屏幕、标注图片，并在启动器里保留可搜索的历史。

![Wox 截图](/images/guide/plugin_screenshot.png)

## 它是什么

查询 `screenshot` 或 `截图` 浏览历史。用 `screenshot new` 开始一次新截图。

编辑器里可以裁剪、添加编号标记、检查颜色、输入像素尺寸、导出 PNG 或 JPEG，并把截图钉成桌面浮层。历史默认保留 15 天。

OCR 是可选的。在 **设置 -> 插件 -> 截图** 中启用以按图片中的文字搜索。可以使用系统 OCR，也可以下载离线 PaddleOCR 模型。

## 常见动作

| 动作 | 用途 |
| --- | --- |
| 复制 | 把图片放到剪贴板 |
| 钉住 | 在桌面上保留浮动预览 |
| 保存到笔记 | 把截图附加到新笔记或已有笔记 |
| 打开 | 用默认图片应用打开文件 |

## 怎么用

1. 运行 `screenshot new`，或把该查询绑定到快捷键。
2. 选择区域，需要时再标注。
3. 之后输入 `screenshot`，按日期或 OCR 文本过滤。
