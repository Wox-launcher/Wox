# 启动器里的浮动笔记

<ReleaseStamp />

Wox 内置浮动笔记，不用切换到其他笔记应用就能记下内容。

![包含清单、表格和引用的 Wox 笔记](/images/notes.png)

## 它是什么

查询 `note` 搜索笔记，或用 `note new` 新建。每条笔记都在独立窗口中打开，支持富文本、清单、表格和图片附件。

| 查询 | 结果 |
| --- | --- |
| `note` | 搜索并重新打开笔记 |
| `note new` | 新建笔记 |
| `note search invoice` | 按标题或正文过滤 |
| `note deleted` | 查看最近删除的笔记 |

笔记可以钉住，包括跨 macOS Spaces。可以导出 Markdown、纯文本或 HTML。云同步可以同步笔记正文；图片只留在本机。

## 从其他插件保存

剪贴板、文件搜索、截图、选区、快速跳转和 Shell 都可以在操作面板里把当前项保存到笔记，不必先手动复制。

## 怎么用

1. 打开 Wox，输入 `note new`。
2. 在笔记窗口里写内容。启动器可以隐藏，笔记窗口会继续留着。
3. 之后输入 `note`，选中对应笔记即可找回。

已删除的笔记会保留 60 天，然后自动清理。
