# 用一个快捷键翻译并替换选中文本

整理一段英文资料时，常见的做法是复制文字、切到翻译工具，再把译文复制回来。如果只是想把笔记里的某一段换成中文，这几次来回切换可以交给 Wox 完成。

下面用一个“翻译为中文”命令，把 **AI 命令** 和 **快捷键查询** 连起来：在可编辑的文本中选中一段话，按下快捷键，等待翻译完成，结果就会粘贴回原来的应用。先用笔记里的短句试一次，更容易看清整个过程。

## 先告诉 AI 要做什么、结果要放哪里

先在 **设置 → AI** 中配置一个可用的提供商和模型。如果还没有配置，可以参考 [AI 设置](/zh/guide/ai/settings)。

接着打开 **设置 → 插件 → AI 命令**，新增或编辑一个命令：

| 字段 | 示例值 |
| --- | --- |
| 名称 | `翻译为中文` |
| 命令 | `translate` |
| 模型 | 选择已经配置好的模型 |
| 提示词 | `Translate the following text to Chinese. Return only the translated text: %s` |
| 默认动作 | `运行并粘贴` |

`translate` 是之后查询中使用的命令关键字；`%s` 是提示词里放入待翻译文本的位置。提示词要求“只返回译文”，是为了尽量避免把解释、开场白也一起粘贴回笔记。

> 待补截图：AI 命令编辑界面，展示 `translate` 命令、含 `%s` 的翻译提示词、已选模型，以及默认动作“运行并粘贴”；不要包含 API 密钥。

**运行并粘贴** 决定了结果的去向。Wox 会等待完整答案返回，再把最终文本写入剪贴板，并向触发前记录的活动窗口粘贴，不会把生成到一半的内容逐段填进去。

## 再让快捷键带上选中的文字

打开 **设置 → 通用 → 快捷键查询**，新增一项：

| 字段 | 示例值 |
| --- | --- |
| 预设 | `静默执行` |
| 快捷键 | 一个未被占用的组合，例如 `ctrl+shift+t` |
| 查询 | `ai translate {wox:selected_text}` |

`{wox:selected_text}` 会在触发时带入当前选中的文字。这样，同一个快捷键可以处理不同的段落，不必每次重新输入查询。

**静默执行** 负责在查询只有一个结果时直接执行它的默认动作。因此，这里两个设置缺一不可：AI 命令的默认动作负责粘贴，快捷键的预设负责省去启动器里的确认。

> 待补截图：快捷键查询编辑界面，选中“静默执行”预设，展示已录入的快捷键和完整查询 `ai translate {wox:selected_text}`。

## 在一段可编辑的文字上试一次

在笔记编辑器中输入一句英文，例如 `Please send me the updated draft tomorrow.`，选中整句，再按下刚才设置的快捷键。

Wox 会把选中文字交给所选模型处理，并在鼠标附近显示等待提示。完整答案返回后，它会回到原来的应用执行粘贴。保持原来的选区和编辑位置不变，译文就可以替换这句话；实际措辞会随模型而变化。

这里依赖目标应用能够接收粘贴。如果选中的是只读网页里的文字，网页原文不会因此被改写。等待期间也尽量不要移动原应用的光标或改变选区，以免结果落到另一个位置。

如果希望先检查译文，把 AI 命令的默认动作改成 **运行**，确认内容后再自行使用。等这套提示词的输出符合预期，再切回 **运行并粘贴**。同样的配置也可以用于语法修正或语气调整，只需要把提示词改成对应任务。
