# 在 Windows 上按空格预览文件

准备上传附件时，文件名相近的几份资料常常让人拿不准：这张图是不是刚导出的版本，这份文档里有没有需要的内容？双击确认会打开另一个应用，还得再回到文件列表。

在 Windows 上，Wox 可以预览已经选中的文件。选中一个文件后按空格，内容会出现在单独的预览面板里，适合在打开或上传前先看一眼。

## 开启一次，之后在文件列表里使用

打开 **设置 → 插件 → 选中内容（Selection）**，开启 **启用空格快速预览**。这个选项默认关闭，需要先手动打开。

然后可以用一张图片试试：

1. 保持 Wox 运行，在 Windows 文件资源管理器里单击选中一张图片。
2. 按下空格键，不需要先唤起 Wox，也不需要额外按住修饰键。
3. 查看弹出的预览面板，确认图片内容。

同样的操作也适用于支持的打开、保存文件对话框。例如给邮件添加附件时，可以先在文件列表里选中图片、按空格确认，再继续选择附件。

## 看内容时，把空间留给预览

空格快速预览会收起查询框和结果列表，让文件内容占据主要空间。它适合确认图片、查看支持的文本文件，或快速检查 PDF、Office 文档；能展示多少内容取决于文件格式和预览支持情况。较大的文档可能先显示文件信息，再加载内容。

触发时需要只选中一个文件。如果按空格没有打开预览，先检查开关是否开启、是否选中了多个文件，以及焦点是否还停在文件列表中。

如果接下来要复制文件路径或打开所在文件夹，可以改用 Wox 的 **选中热键**。它会对当前选中的文件显示常规操作，和这里的直接预览是两个入口。

空格快速预览目前仅支持 Windows。macOS 可以直接使用 Finder 自带的 Quick Look；Wox 在 macOS 和 Linux 上不启用这个空格预览开关。
