# 在 Wox 中使用 Launchpad 风格的应用网格

有时你记得一个应用的图标，却一时想不起名字。比如偶尔才用一次的图片工具，知道装过，却不知道该输入什么来找。此时先浏览一遍图标，可能比反复猜名称更直接。

Wox 的内置应用插件提供了一个 Launchpad 风格的网格。唤起 Wox 后输入：

```text
app launchpad
```

应用会以较大的图标排列，名称显示在图标下方。找到熟悉的图标后，选中对应应用并打开即可。

![Wox 应用启动台网格](/images/did-you-know-wox-app-launchpad.png)

这个入口适合“看看有什么可用的应用”。如果已经知道要打开哪个程序，直接在 Wox 中输入名称搜索通常更省事，不必先进入网格。

## 用一个快捷键打开应用网格

经常按图标找应用的话，可以把这条查询保存下来：

1. 打开 **设置 → 通用 → 快捷键查询**，新增一项。
2. 选择 **普通查询** 预设，查询填写 `app launchpad`。
3. 录入一个未被占用的快捷键并保存。

之后按下这个快捷键，Wox 就会直接显示应用网格。这里选择普通查询，是因为你还需要看着网格挑选应用。

网格展示的是应用插件收录并适合在这里显示的条目，并非系统中所有软件的完整清单。例如没有可用图标的条目可能不会出现。如果没看到某个应用，可以回到普通查询，输入名称继续查找。
