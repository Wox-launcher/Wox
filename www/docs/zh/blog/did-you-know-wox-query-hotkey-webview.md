# 用快捷键打开常用网页面板

查一下状态页、看一眼时间线，往往只需要几秒钟。为了这一下打开浏览器、寻找标签页，再切回手头的窗口，有时比查看内容本身还麻烦。

Wox 网页搜索中的 WebView 选项可以把常用网站放进一个小面板，再用快捷键直接打开。下面以 X 为例，从一条能运行的查询开始，最后把它变成固定入口。这项功能支持 Windows、macOS 和 Linux；Linux 需要 WebKitGTK 4.1 或 4.0。

## 先确认网站能在 Wox 中打开

在 **设置 → 插件 → 网页搜索** 中添加名称、触发关键词和 URL，并开启 **在 WebView 中打开**。例如：

| 关键字 | 网站 | 对应查询 |
| --- | --- | --- |
| `x` | `https://x.com` | `x ` |
| `ig` | `https://www.instagram.com` | `ig ` |

触发关键词后的空格不可省略，保存到快捷键查询时也要保留。唤起 Wox，输入 `x `，先看网页是否正常显示。如果需要登录，按网站页面的提示完成登录。

![通过快捷键查询打开的 Wox 网页预览](/images/did-you-know-wox-webview-hotkey.png)

也可以换成自己常看的状态页或仪表盘：打开 **设置 → 插件 → 网页搜索**，添加站点关键字和完整 URL。例如把关键字设为 `status`，之后使用的查询就是 `status `。记得为该条目开启 **在 WebView 中打开**。

先手动测试这条查询，是为了确认站点配置和页面都能正常工作，再给它绑定快捷键。

## 把这条查询绑定到快捷键

打开 **设置 → 通用 → 快捷键查询**，新增一项：

| 字段 | 示例值 |
| --- | --- |
| 预设 | `预览查询` |
| 快捷键 | 一个未被占用的组合，例如 `ctrl+shift+x` |
| 查询 | `x ` |

**预览查询** 会隐藏查询框和工具栏，让页面占据面板的主要空间。保存后按下快捷键，就能直接打开这个网页面板，不必再输入 `x `。

> 待补截图：快捷键查询编辑界面，选中“预览查询”预设，展示快捷键与 `x ` 查询；让读者能对应上表中的三个字段。

先用默认大小看一次。如果页面太窄，或出现横向滚动，再调整快捷键查询的宽度、位置等显示选项。不同网站的排版不同，适合时间线的宽度未必适合一整张仪表盘。

配置其他网站时，沿用同样的方式，把查询换成 `ig ` 或自己设置的关键字即可。

## 经常用鼠标，也可以放到托盘

如果更习惯点击图标，可以在 **设置 → 通用 → 托盘查询** 中添加同一个网站：

| 字段 | 示例值 |
| --- | --- |
| 图标 | 一个容易认出该网站的图标 |
| 查询 | `x ` |
| 隐藏查询框 | 开启 |
| 隐藏工具栏 | 开启 |
| 宽度 | 可先试 `420`，再按页面调整 |
| 最大结果数 | `5` |

点击托盘或菜单栏里的图标后，Wox 会在托盘附近打开并执行查询。这里访问的仍是同一个站点，只是多了一个鼠标入口；不需要为了使用托盘再配置一次站点。

![通过 Wox 托盘查询打开网页预览面板](/images/did-you-know-wox-webview-tray-query.png)

需要展开阅读、对照多个页面，或网站在小面板里不方便操作时，可以使用结果操作中的 **在浏览器中打开**，继续在浏览器里处理。

![在 Wox 网页预览中用操作打开浏览器](/images/did-you-know-wox-webview-open-browser.png)

如果某个网站无法在面板中正常登录或显示，可以通过上面的操作交给浏览器打开。
