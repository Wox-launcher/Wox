# Wox 的 Raycast 支持

一个启动器用久了，里面装的不只是几个插件。你可能为常用操作设置了快捷键，把经常访问的页面存成快速链接，也留下了笔记和剪贴板历史。这些东西一点点积累起来，才形成了顺手的工作方式。

从 Wox v2.4.9 开始，如果你在同一台电脑上使用 Raycast，可以在 Wox 的初始引导中导入支持的设置和数据，也可以导入本机已安装的兼容插件。我们希望你尝试 Wox 时，不必先花时间把这些习惯从头搭建一遍。

这项支持有一条明确的边界：**Wox 不提供 Raycast 商店。Raycast 插件只能在新手引导的迁移步骤中，从用户本机已有的安装中选择并导入。**

![Wox 新手引导中的 Raycast 导入列表，显示快捷键和常规设置](/images/blog/raycast-import-onboarding.png)

## 为什么支持导入

启动器是一种很个人的工具。打开哪个应用、给命令起什么别名、用什么快捷键，这些选择往往是长期使用中慢慢调整出来的。即使两个工具都能完成同一件事，要重新找回熟悉的操作也需要时间。

我们希望用户能够在了解 Wox 的同时，带上自己已有的配置。比如，你在 Raycast 里保存了常用网页和快捷键，导入后可以先检查哪些项目能迁移，再从熟悉的操作开始使用 Wox。支持的设置、快速链接、片段、笔记和剪贴板历史也可以按需选择；不同产品的功能并不完全相同，因此导入界面会标出无法迁移或需要留意的项目。

插件同样如此。一个已经安装的插件可能承载了你每天都会用到的小工具。对于兼容的本地插件，我们提供运行其部分命令的能力，让你可以尝试继续使用它，而不必一开始就寻找替代品。

## 为什么不提供 Raycast 商店

插件是作者花时间编写和维护的作品。一个商店除了展示插件，还涉及作品、资源和发布渠道的使用与分发。我们尊重 Raycast 和插件作者在这些方面的权利，也认为支持用户迁移，并不意味着 Wox 应该把另一个产品的商店直接搬进来。

我们知道有些其他软件选择提供类似的商店体验。考虑到版权和分发边界，Wox 选择不这么做：不在 Wox 中提供 Raycast 商店，也不通过它浏览或下载 Raycast 插件。这是我们对产品边界作出的选择。

Wox 提供的是用户主动发起的一次性本地导入：引导程序根据 Raycast 备份中的插件信息，查找这台电脑上已有的对应文件，并让用户选择可导入的项目。备份包含插件引用，不包含插件的可执行文件；如果本地文件不存在，Wox 不会尝试从商店下载。这个入口用于引导中的迁移，不是一个持续同步的商店。

## 如何导入

在 Windows 或 macOS 上，先保留这台电脑已安装的 Raycast 和你希望导入的插件。Wox 首次运行时会显示新手引导；引导中检测到 Raycast 后，会提供迁移选项。如果你已经完成过引导，可以打开 Wox 的**设置 → 关于 → 新手引导**，重新进入引导程序。

1. 在 Raycast 中搜索 `export setting`，导出设置和数据，保存 `.rayconfig` 文件和导出时使用的口令。请使用 Raycast 2.0 或更新版本导出。
2. 在 Wox 新手引导中进入迁移步骤，选择 Raycast、导出文件并输入口令。
3. 查看可迁移的项目，选择需要带入 Wox 的设置、数据和本地插件，然后开始导入。未找到、身份不匹配或当前不受支持的插件会在列表中说明原因。

导入完成后，可以在 Wox 中输入插件的触发关键字并跟随命令提示使用。插件的设置可在 Wox 的插件设置中查看；如果一个命令需要的设置未包含在备份里，可能需要重新填写。

## 导入之后，哪些地方可能不同

Wox 为 Raycast 插件提供的是兼容层，目前只覆盖部分 API。列表、操作和部分表单等能力可以映射到 Wox 的界面，但 OAuth、后台定时任务和菜单栏功能等尚不支持。插件能够导入，不代表它的每个命令都能运行；具体取决于插件使用的 API 和当前系统。

数据也不一定能逐项保持原来的行为。例如，导入的片段会作为 Wox 笔记保存，动态占位符按原文保留，关键字不会自动展开。建议导入前查看列表中的说明，完成后试用常用命令和快捷键。

如果需要寻找更多扩展，可以访问 [Wox 插件商店](/zh/store/plugins)。顺带一提，Windows 上也支持从 Flow Launcher 导入设置和兼容的本地插件；虽然它最初基于 Wox 分叉，出于同样的版权和分发考虑，Wox 也不直接提供它的插件商店。
