# 网页预览插件

网页预览可以在 Wox 里打开配置好的网站。目前支持 Windows 和 macOS。

![网页预览插件](/images/guide/plugin_webview.jpg)

## 快速开始

```text
webview x
webview ig
```

默认关键字包括 `x`（X）和 `ig`（Instagram）。在 **设置 -> 插件 -> 网页预览** 中添加自己的关键字和 URL。可以为每个站点设置 user agent、注入 CSS，或选择在后台保持运行。在操作面板（`Ctrl+W` / `Cmd+W`）中使用 **关闭网页** 可以销毁当前页面并释放内存。通过快捷键打开的全预览窗口在启用后台运行时还会提供 **隐藏网页**。

用 **预览查询** 预设绑定快捷键查询，可以把网站开成紧凑面板。见 [快捷键](../../usage/hotkeys.md)。

需要完整浏览器时，使用 **在浏览器中打开** 动作。
