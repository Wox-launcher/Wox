# 文本片段插件

文本片段用于保存常用内容，之后可以快速复制、粘贴，或者在输入关键词时自动展开。

## 创建片段

1. 打开 Wox 设置 → 已安装插件 → 文本片段。
2. 添加片段，填写名称和需要复用的文本。关键词可以留空。
3. 如果希望输入关键词时自动替换，请在此设备开启**启用自动展开**。该选项默认关闭。

例如，将关键词设为 `;email`，文本设为 `hello@example.com`。开启自动展开后，在受支持的输入框中输入 `;email`，它就会被替换为 `hello@example.com`。

关键词支持可打印 ASCII 字符，包括空格。输入完整关键词后会立即替换，不需要再按回车或空格。如果希望输入末尾空格或标点后才触发展开，请把它也写进关键词；如果替换后还要保留该字符，也要把它写进文本。关键词不能重复。如果同步后出现关键词冲突，相关片段的自动展开会暂停，直到冲突解决。

## 查找和使用片段

在 Wox 中输入 `snip` 可列出片段；输入 `snip email` 可按名称、关键词或文本搜索。按回车复制展开后的文本；有可用的目标应用时，也可以在操作面板中选择粘贴。这些操作无需开启自动展开。

自动展开后立即按退格键，Wox 会尝试恢复关键词。能否撤销取决于目标编辑器和插入的文本。

## 插入变量

在文本框中输入 `{`，或点击闪电按钮插入变量。复制、粘贴或自动展开片段时，变量会被替换为对应内容。

| 变量 | 结果 |
| --- | --- |
| `{wox:date}` | 今天的日期 |
| `{wox:date?format=yyyy-MM-dd}` | 按指定格式显示的日期 |
| `{wox:clipboard_text}` | 当前剪贴板文本 |
| `{wox:uuid}` | 新生成的唯一标识符 |

日期格式支持 `yyyy`、`MM`、`dd`、`HH`、`mm` 和 `ss`。不支持的占位符或日期格式会保留原样；如果无法读取剪贴板文本，展开会取消。

## 同步和权限

启用云同步后，片段作为一项设置同步；不同设备同时修改时遵循现有的整项设置冲突处理方式。自动展开开关只保存在本机，需要在每台设备上分别开启。

自动展开需要访问键盘输入和当前聚焦的可编辑控件。macOS 上需要授予 Wox 辅助功能权限。Linux 桌面需要提供辅助功能信息；Wayland 还需要访问 `/dev/input` 和 `/dev/uinput`。部分应用、输入法或桌面会话无法提供足够的信息，因此可能无法展开。无法获取所需权限时，文本片段设置中会显示状态提示。

某些展开方式会临时使用剪贴板。剪贴板能否恢复取决于平台，也可能受到同时发生的复制操作影响；Wayland 上展开后的文本可能会留在剪贴板中。
