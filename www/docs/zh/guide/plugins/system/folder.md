# 文件夹插件

文件夹插件会在输入路径时补全目录。它监听全局输入，所以 `~/Documents` 或 `%LOCALAPPDATA%` 这类路径可以直接变成文件夹结果。

![文件夹插件](/images/plugin_folder.png)

## 快速开始

```text
~/Documents
C:\Users
%LOCALAPPDATA%
```

按 `Enter` 打开文件夹。操作面板可以进入该目录、打开所在位置、在这里执行 Shell 命令，或切换是否显示隐藏文件。

## 收藏

打开 **设置 -> 插件 -> 文件夹** 可以保存带名称的收藏路径。收藏按操作系统分开存储。
