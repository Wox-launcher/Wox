# 快速跳转插件

快速跳转以前叫 Explorer。它是上下文插件：当资源管理器、Finder 或打开/保存对话框处于活动状态时，帮你在文件夹之间跳转。触发关键字是 `jump`。

目前支持 Windows 和 macOS。Linux 没有这个插件。

![快速跳转插件](/images/plugin_quickjump.png)

## 在文件管理器中

当 File Explorer 或 Finder 聚焦时打开 Wox，输入当前目录下子文件夹或文件名的一部分：

```text
Documents
Downloads
project
```

当前目录中的匹配会排在其他索引结果前面。选中文件夹即可跳转。需要显示位置、新窗口打开或保存到笔记时，使用操作面板。

## 在打开/保存对话框中

当对话框处于激活状态时打开 Wox，可以跳转到：

- 当前文件管理器已打开的文件夹
- 当前应用最近使用过的文件夹
- 已保存的快速跳转路径
- Desktop、Documents、Downloads 等常用系统目录

Wox 也可以导航自己的 Windows 文件夹选择器，包括 Office、Foxmail 这类 32 位宿主。

## 已保存路径和忽略的应用

打开 **设置 -> 插件 -> 快速跳转** 可以：

- 按操作系统保存 `jump add` 用的文件夹路径
- 忽略不应触发快速跳转的应用

```text
jump add
```

## 快速切换

当文件管理器和打开/保存对话框同时可用时，快速跳转可以在两者之间切换，让你回到正在浏览的文件夹。

## 注意事项

- 没有受支持上下文时，插件会保持安静。
- 如果某个应用的对话框表现异常，把该应用加入忽略列表即可，不必关闭整个插件。
