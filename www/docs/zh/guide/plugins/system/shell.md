# Shell 插件

Shell 可以从 Wox 运行命令，并保留命令历史。用 `>` 明确进入 shell 查询。部分命令也可以被全局识别。

![Shell 插件](/images/guide/plugin_shell.jpg)

## 快速开始

```text
> git status
> npm test
```

输入 `>` 和一个空格，右侧会自动启动交互终端。选中「新建 Shell」按 Enter，即可进入终端输入，也可以在查询框继续输入单次命令。交互式 PowerShell、Bash 和 Zsh 每个会话只生成一条历史，以首条命令为标题。已完成的命令和最近的输出会保存到这条记录。按 `Esc` 返回查询框，按 `Shift+Esc` 向 Shell 发送 Escape。离开 Shell、隐藏预览或隐藏 Wox 都会结束会话。

用上下键选中历史记录，按 Enter 在 Shell 预览里打开。交互命令的历史会恢复到实时终端里，可以上翻查看以前的输出，也可以继续执行命令。继续执行的命令会追加到同一条历史记录。按 `Esc` 回到查询框。单次命令可在操作面板中选择「重新执行」。

正在运行的命令会在历史里显示指示器。可以在插件设置里指定默认工作目录，或为单条命令选择目录（家目录、上次使用的目录或自定义目录）。

操作面板可以把输出保存到笔记、重新运行上一条命令，或在系统终端中打开当前命令。
