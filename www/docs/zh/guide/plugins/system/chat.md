# 对话插件

对话会在 Wox 里打开一次 AI 会话。使用前先配置 AI provider。

![对话插件](/images/guide/plugin_chat.jpg)

## 快速开始

```text
chat How do I use Wox?
```

你可以继续历史会话、切换模型、附加选中文本、文件或图片，并使用已配置的 MCP 工具。在对话输入框中输入 `/` 可以选择模型或技能。

会话可以弹出到独立窗口。启动器隐藏后，未发送的草稿仍会留在那个窗口里。

## 提及插件

在对话输入框中输入 `@` 并选择插件，就可以让 AI 使用该插件提供的工具。然后描述你想完成的任务。列表中只会显示已启用且提供工具的插件；选中插件的工具在同一会话的后续对话中仍然可用。

例如，提及 Unsplash 插件并让它更换桌面壁纸：

![在对话中使用 @Unsplash](/images/guide/ai-chat-at-plugin.png)

## 设置

| 设置 | 用途 |
| --- | --- |
| 回退搜索 | 当非防抖插件尚未返回结果时，提供 AI Chat 回退结果。防抖插件的结果仍可能稍后出现。 |
| 默认模型 | 新会话使用的 provider 和模型。发送对话时也会记住当前模型，供下一次新建会话使用。 |

Provider、MCP 服务器和技能在 **设置 -> AI** 中配置，不属于 AI Chat 插件设置。Provider 的配置方法见 [AI 设置](../../ai/settings.md)。插件的触发关键词也可以在插件设置页修改。

## 隐私

对话内容会发送给选中的模型 provider。不要把密钥、私有文档或选中文本粘贴给在线模型，除非这符合你的工作流。
