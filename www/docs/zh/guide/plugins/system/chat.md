# 对话插件

对话会在 Wox 里打开一次 AI 会话。使用前先配置 AI provider。

![对话插件](/images/plugin_chat.jpg)

## 快速开始

```text
chat How do I use Wox?
```

你可以继续历史会话、切换 Agent、附加选中文本、文件或图片，并在选中的 Agent 支持时使用已配置的 MCP 工具。

会话可以弹出到独立窗口。启动器隐藏后，未发送的草稿仍会留在那个窗口里。

## 设置

| 设置 | 用途 |
| --- | --- |
| 默认模型 | 新会话使用的模型 |
| Agent | 保存好的 prompt、模型、图标和工具预设 |
| MCP 服务器 | 提供给 Agent 的工具，支持 JSON 导入和 OAuth |
| 技能 | Agent 可以调用的本地或远程可复用技能 |
| 自动聚焦 | 打开对话时聚焦输入框 |
| Fallback 入口 | 没有更好的插件匹配时，显示一个对话结果 |

输入框里的 `{wox:...}` 占位符会显示成 token。输入时，编辑区会从 1 行长到最多 5 行。

## 隐私

对话内容会发送给选中的模型 provider。不要把密钥、私有文档或选中文本粘贴给在线模型，除非这符合你的工作流。
