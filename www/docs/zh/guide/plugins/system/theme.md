# 主题管理

主题插件可以应用、安装、移除和恢复 Wox 主题。

## 快速开始

```text
theme
```

`theme` 会列出当前主题、系统主题和商店主题。按 `Enter` 应用主题。

在“设置 → 已安装主题”中，Wox Auto 会跟随系统浅色/深色外观。也可以在列表底部新建并命名 Auto 主题，分别挑选浅色和深色端点，再像普通主题一样应用。用户自己的 Auto 主题可在详情页编辑；系统自带的 Wox Auto 配对保持只读。

AI 辅助位于“设置 → 主题编辑器”，需要先配置模型提供方。见 [主题生成](../../ai/theme.md) 和 [主题商店](/zh/store/themes)。
