# 关注事项插件

关注事项会收集插件发来的、可以稍后处理的通知。例如，Windows 上的文件搜索索引服务有更新时，文件搜索插件可以在这里留下一条通知。重启 Wox 后，未读事项仍会保留。

![关注事项显示有两条未读的 GitHub 通知](/images/system-plugin-attention.png)

## 打开关注事项

- 在 Wox 中输入 `attention`。列表先显示未读事项，再显示已读事项。在 `attention` 后加上搜索词，可以按标题、描述或来源插件筛选。
- 查询框旁显示未读数量时，可以点击它，也可以在 macOS 上按 `Cmd+U`，在 Windows 或 Linux 上按 `Ctrl+U`。

## 处理事项

如果事项提供「打开」动作，执行后会跳转到相关查询或来源插件的设置，并将该事项标记为已读。要直接更改阅读状态，可以在[操作面板](../../usage/action-panel.md)中选择「标记为已读」或「标记为未读」。
