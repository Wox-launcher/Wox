# 选中内容插件

选中内容插件处理你在其他应用里选中的文本或文件。使用选中热键，或在 Wox 捕获选区后查询 `selection`。

## 快速开始

1. 在其他应用中选中文本或一个文件。
2. 按选中热键，或打开 Wox 输入 `selection`。
3. 复制路径、打开所在文件夹、预览文件、保存到笔记，或运行 Shell 命令。

`selection preview` 只返回文件预览。

## 空格 Quick Look

在 Windows 上，打开 **设置 -> 插件 -> 选中内容**，启用 **空格 Quick Look**。在资源管理器或打开/保存对话框中选中一个文件，再按 `Space`。见 [预览](../../usage/preview.md)。

macOS 默认关闭这项，因为 Finder 已有 Quick Look。
