# 快捷键

Wox 有一个主启动热键，也可以再为准备好的查询绑定快捷键。在 **设置 -> 常规** 中修改。

## 主热键

默认切换快捷键：

| 平台 | 默认 |
| --- | --- |
| Windows | `Alt + Space` |
| macOS | `Command + Space` |
| Linux | `Ctrl + Space` |

另外还有 **选中热键**。它会针对当前选中的文本或文件打开 Wox，方便选区、网页搜索和 AI 命令这类插件继续处理。

在 macOS 上，如果录制热键时提示权限，需要授予辅助功能权限。在 Linux Wayland 上，`Ctrl + Space` 这类普通组合走桌面门户；双修饰键和 CapsLock 组合需要额外输入权限。见 [Wayland 常见问题](../faq.md#wayland-double-modifier-hotkeys)。

## 快捷键查询

快捷键查询把一个快捷键绑定到一段查询。不用先打开 Wox 再输入 `webview x` 或 `window group Work`，按一下就能执行。

打开 **设置 -> 常规 -> 快捷键查询**，新增一行，并从预设开始：

| 预设 | 用途 |
| --- | --- |
| 普通查询 | 显示启动器并执行查询 |
| 预览查询 | 隐藏查询框和工具栏，适合 WebView 面板和文件预览 |
| 静默执行 | 只有一个明确动作时，不显示启动器直接执行 |
| 自定义 | 保留预设默认值，再覆盖位置、宽度、结果数或界面元素 |

之后仍可以覆盖窗口位置、宽度、结果数，以及查询框和工具栏是否显示。

设置里还有 **查询测试** 按钮，不用离开页面就能试热键、快捷方式和托盘查询。

### 示例

| 查询 | 快捷键会做什么 |
| --- | --- |
| `app launchpad` | 打开应用网格 |
| `webview x` | 打开紧凑的 X 面板 |
| `window group Work` | 恢复已保存的工作区 |
| `ai translate {wox:selected_text}` | 翻译当前选中文本 |

静默翻译也是同一套做法：先创建一个 AI 命令，再用 **静默执行** 预设绑定快捷键。见 [AI 命令](../ai/commands.md)。

## 托盘查询

托盘查询是快捷键查询的鼠标版本。在 **设置 -> 常规 -> 托盘查询** 中添加图标和查询。点击托盘或菜单栏图标后，Wox 会在托盘附近打开并执行该查询。

适合仪表盘、WebView 站点、剪贴板历史（`cb`）或笔记（`note`）。

## 其他内置热键

| 功能 | 位置 |
| --- | --- |
| 听写：单击 / 双击 / 按住 | **设置 -> 插件 -> 听写** |
| 截图 | **设置 -> 插件 -> 截图**，或查询 `screenshot` |
| 热键总览 | 查询 `hotkeys` 查看已注册快捷键 |
