# 操作面板

操作面板是结果的第二步。`Enter` 执行主要动作；操作面板展示插件附加在该结果上的其他动作。

![操作面板](/images/guide/action_panel.jpg)

## 打开方式

1. 选中一个结果。
2. Windows/Linux 默认按 `Ctrl + K`，macOS 按 `Command + K`。可在 **设置 -> 常规** 中修改。
3. 用键盘选择动作并按 `Enter`。

可以在操作面板里输入文字过滤动作。本地化动作名也支持英文别名，所以 `copy`、`open`、`delete` 仍然能找到对应命令。

## 常见动作

动作取决于插件和结果类型：

| 结果 | 常见动作 |
| --- | --- |
| 应用 | 打开、显示所在目录、复制路径、卸载（Windows）、终止运行中的应用 |
| 文件 | 打开、打开所在文件夹、移入废纸篓、显示系统上下文菜单、保存到笔记 |
| 剪贴板项 | 复制、粘贴到当前应用、收藏、编辑标题、编辑文本、删除、保存到笔记 |
| 书签或 URL | 在浏览器中打开 |
| 插件商店结果 | 安装、卸载、更新、打开网站 |
| 计算器 / 转换器结果 | 复制格式化结果、原始结果，或问题和答案 |
| 任意结果 | 重置基于使用次数的排序，或把当前查询存成快捷方式 |

## 什么时候用

当默认 `Enter` 动作不是你想要的动作时，打开操作面板。它也是发现插件能力的最快方式，不需要先翻设置或文档。
