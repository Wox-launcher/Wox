# Wox 停更了吗？对比 Flow / Raycast / PowerToys（2026）

<ReleaseStamp />

## Wox 是不是停更了？

Wox v1 确实停过一段时间。[Flow Launcher](https://github.com/Flow-Launcher/Flow.Launcher) 从那条 Windows v1 代码线发展而来，是 v1 时代的 Windows 精神续作 / 分支。

本仓库是 **Wox v2** 重写。2026 年仍在为 Windows、macOS 和 Linux 发正式版。请看 [GitHub Release](https://github.com/Wox-launcher/Wox/releases) 或[更新日志](/zh/changelog/)。

## Wox vs Flow Launcher

Flow Launcher 属于 Wox v1 谱系，专注 Windows，插件生态也以 Windows 为主。

Wox v2 是原生的 **Windows · macOS · Linux** 启动器。需要三端同一套启动器时，用这个仓库里的 Wox v2。只在 Windows 上用、并且已经习惯 Flow，继续用 Flow 也完全合理。

## Wox vs Raycast

Raycast 更精致，基本闭源。macOS 和 Windows 都有正式产品。

Wox 开源（GPL-3.0），Windows、macOS、Linux 都在发正式版。想要 Raycast 那种完成度，用 Raycast。想要开源、三端都发的启动器，用 Wox。

## Wox vs PowerToys Run

[PowerToys](https://learn.microsoft.com/windows/powertoys/) 是微软的 Windows 工具集。PowerToys Run（以及 Command Palette）只是其中一项。

Wox 是专职启动器：插件、剪贴板历史、文件索引、主题和商店。如果你本来就要用整套 PowerToys，用它即可。如果你要的是启动器本身，并且还要用 macOS 或 Linux，用 Wox。
