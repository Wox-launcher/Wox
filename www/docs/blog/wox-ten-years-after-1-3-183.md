# Ten years ago today

On November 11, 2016, we released Wox 1.3.183. The release notes were just two words, “bug fixes.” Seeing the three `.exe` files listed there again, ten years later, brings back what installing software was like back then. [Wox 1.3.183 release notes](https://www.woxlauncher.com/changelog/#release-v1-3-183)

Ten years ago, Stack Overflow was where we turned with technical questions we couldn’t answer, hoping an expert would reply. Ten years later, everything has changed. Now we want to ask AI about everything.

Wox ran only on Windows back then, and Raycast hadn’t appeared yet. We wrote the code by hand and shipped at a slower pace. The previous release, 1.3.67, had come out in May, nearly six months earlier. These days we have AI to help us write code, Wox releases come much more frequently, and the app runs on Windows, macOS, and Linux.

Ten years later, the basic rhythm of a launcher still feels familiar. Press a shortcut, type a few letters, and hit Enter to open an app. I wonder if we’ll still use computers that way in another ten years. What if the computer itself became a powerful agent that could understand requests through conversation, generate whatever interface was needed, and get the work done on the spot? Would we still need to open individual desktop tools? What would a launcher like Wox look like then?

Let’s come back to this on November 11, 2036, and see.
